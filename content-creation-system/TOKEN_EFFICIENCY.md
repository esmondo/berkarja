# Token Efficiency Principles Applied

- **1. No redundancy**: Each skill = single focused task.
- **2. Lazy loading**: Sub-agents load only when invoked.
- **3. Structured output**: JSON schemas prevent verbose responses.
- **4. Shared resources**: Knowledge base referenced, not duplicated.
- **5. Positive instructions**: "Do X" not "Don't do Y".
- **6. Declarative > verbose**: Bullet points, clear delimiters.

**Estimated**: ~1,200 tokens for full system (vs 5,000+ for verbose prompts).
